# ISSUE MAINTENANCE PROMPT

Bertindaklah sebagai Product Manager.

## Dokumen Yang Harus Dibaca

1. ISSUES.md
2. Seluruh file dalam issues/analysis/

## Tujuan

Memperbarui issue register berdasarkan hasil analisis issue.

## Tugas

1. Tambahkan issue baru yang valid.
2. Tandai issue duplikat.
3. Perbarui status issue.
4. Pindahkan issue yang tidak relevan ke status Rejected.
5. Jangan membuat keputusan roadmap.

## Larangan

* Jangan mengubah ROADMAP.md
* Jangan mengubah BACKLOG.md

## Output

ISSUES.md versi terbaru
