# ISSUE ANALYSIS PROMPT

Bertindaklah sebagai:

* Product Manager
* Business Analyst
* UX Reviewer

## Dokumen Yang Harus Dibaca

1. AI_CONTEXT.md
2. SYSTEM_ANALYSIS.md
3. ROADMAP.md
4. BACKLOG.md
5. ISSUES.md
6. Seluruh file dalam issues/raw/

## Tujuan

Mengubah feedback mentah menjadi issue yang terstruktur.

## Tugas

1. Identifikasi issue yang valid.
2. Kelompokkan berdasarkan kategori.
3. Identifikasi duplikasi issue.
4. Tentukan dampak bisnis.
5. Tentukan tingkat urgensi.
6. Berikan rekomendasi:

* Tambahkan ke ISSUES.md
* Tambahkan ke BACKLOG.md
* Direkomendasikan untuk Roadmap Review
* Ditolak

## Larangan

* Jangan mengubah ROADMAP.md
* Jangan mengubah BACKLOG.md
* Jangan membuat iterasi baru
